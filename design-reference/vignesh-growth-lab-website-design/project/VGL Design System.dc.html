Three accents, each with one job: violet for structure and wayfinding, cyan for technology, green exclusively for WhatsApp actions. Never a gaming/crypto look: no neon floods, no glow text — accents stay lines, marks and icons.

Spacing, rules & layout

Page container: max-width 1200px · gutter clamp(20px, 5vw, 72px). Content hugs the left edge; air lives on the right.

Section rhythm (responsive tokens): major sections use clamp(52px, 7vw, 88px) (≈52–64px mobile, 64–80px tablet, 88px desktop); secondary sections clamp(44px, 6vw, 64px). Never a fixed 88px at every width. Anchored sections carry scroll-margin-top:84px for the sticky header.

320px-safe grids: always repeat(auto-fit, minmax(min(100%, Npx), 1fr)) — the min(100%, …) guard stops N-px tracks forcing horizontal scroll on narrow phones.

Comparison tables: real table with caption + scope attrs and visible Yes/No labels on desktop; below 760px the same data renders as stacked per-criterion cards (VGL line first, in accent-200).

Video frames: native video with controls, playsinline and preload="metadata" inside a .card — no fake play buttons, no visible filenames.

Grids: repeat(auto-fit, minmax(250–320px, 1fr)) with 14–18px gaps — this is what makes every page collapse cleanly to mobile without media queries.

Fading rule:

1px, transparent over 48px at each end. Short accent marks (the 44px kicker dash) stay solid.

Production patterns

Missing-video editor state

Business or project name Video will be added before launch

Real players: native controls, playsinline, preload="metadata", configurable poster + label, visible caption, transcript slot. Never a bare broken src, never a fake play button on a real video.

Proof strip (service pages)

One factual result MSME Registered

One real, project-specific result per service — never generalised into a guarantee. Same strip grammar as the homepage trust strip.

Form states

✅ Success message

Field / global error text — #f0a3a3

Selects start on a selected+disabled "Choose a…" option; submit disables while sending (duplicate-submission protection); focus returns to the button after success or failure.

Disabled social icon

Unconfirmed profiles render as a disabled icon with an accessible "coming soon" label — never a link to a generic homepage. Every real external link carries rel="noopener noreferrer".

Case-study media variations

One template, conditional blocks in fixed order: results → written testimonial (NextGen) → demonstration video (AI automation) → gallery (real images, or editor slots only where assets are expected) → CTA. Empty blocks collapse — no forced four-slot galleries, no invented screenshots. Video headings are per-project ("Workflow demonstration", never "Watch it run" for a testimonial).

Mobile states

≤900px the nav collapses to a 44px hamburger (aria-expanded/controls, Escape closes, focus moves into the menu and returns on close, body scroll locks). ≤760px the comparison table becomes stacked per-criterion cards. ≤820px the contact page stacks: WhatsApp card → form → details → process. Founder portrait is never sticky on mobile.
